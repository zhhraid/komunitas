# Komunitas Silek

WordPress project untuk landing page one page website komunitas/perguruan Silek.

Custom theme utama ada di:

```text
wp-content/themes/silek-landing
```

Catatan lokal:

- `wp-config.php` tidak di-upload karena berisi konfigurasi database lokal.
- Folder `wp-content/uploads` tidak di-upload agar media lokal tidak memenuhi repository.
